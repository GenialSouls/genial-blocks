Native, accessible WordPress block editor blocks from GenialSouls.

== Description ==

Genial Blocks provides native WordPress block editor blocks including Advanced
Heading and Advanced Button. Advanced Heading supports semantic levels, native
alignment, typography, color, spacing, and an optional subtitle. Advanced Button
provides accessible link behavior, target safety, layout, colors, borders, and
spacing controls.

== Installation ==

1. Upload the `genial-blocks` folder to `/wp-content/plugins/`, or install the
   plugin ZIP from the WordPress admin.
2. Activate Genial Blocks from the Plugins screen.
3. Insert Advanced Heading or Advanced Button from the block inserter.

== Frequently Asked Questions ==

= Does this plugin require another page builder? =

No. Genial Blocks uses the native WordPress block editor.

= Does Advanced Button load remote assets? =

No. The plugin does not load remote runtime assets or external services.
