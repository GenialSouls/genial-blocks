Native WordPress blocks for structured content, interactive sections, pricing presentations, and responsive layouts.

== Description ==

Genial Blocks adds a focused collection of native blocks to the WordPress block editor. Build clearer content sections, calls to action, feature lists, FAQs, tabs, pricing presentations, progress indicators, statistics, and responsive layouts without requiring a separate page builder.

Each block works inside the familiar WordPress editor and provides focused controls for content, colors, spacing, borders, typography, links, or responsive behavior where appropriate.

== Build More with the WordPress Block Editor ==

Genial Blocks is designed for creating useful page sections directly in the WordPress block editor. Use individual blocks on their own or combine them inside Container layouts to build landing pages, service pages, product sections, pricing areas, documentation, and other structured content.

Interactive blocks use semantic controls and keyboard-aware behavior where applicable. Links opened in new tabs receive safe relationship attributes, and animated Counter and Progress Bar effects respect reduced-motion preferences.

== 10 Blocks Included ==

= Advanced Heading =

Create semantic headings from H1 through H6 with optional subtitles, alignment, typography, text color, and spacing controls.

= Advanced Button =

Add flexible link buttons with custom URLs, optional new-tab behavior, responsive width, hover colors, borders, radius, and padding controls.

= Info Box =

Highlight important content with a title, description, optional local icon, responsive icon placement, CTA link, colors, borders, and spacing.

= Accordion =

Organize expandable content into multiple disclosure items. Choose whether one item or multiple items can remain open.

= Counter =

Display numeric statistics with start and end values, prefixes, suffixes, labels, decimal places, alignment, and optional count-up animation.

= Icon List =

Create repeatable lists using bundled icons, optional item links, alignment, icon sizing, colors, and spacing controls.

= Tabs =

Organize related content into interactive tabs with keyboard navigation and configurable tab and content styling.

= Pricing Table =

Present a pricing plan with a name, subtitle, price, billing period, previous price, badge, feature list, and optional CTA link. The block presents pricing information; it does not process payments.

= Progress Bar =

Show completion or progress values with configurable minimum and maximum values, labels, colors, height, radius, and optional animation.

= Container =

Arrange nested Gutenberg content inside a responsive layout container with configurable width, direction, alignment, justification, gap, spacing, colors, borders, and minimum height.

== Designed for the Native Editor ==

Genial Blocks uses the native WordPress block editor and does not require another page builder. Its curated icon set is bundled with the plugin, and the plugin does not require a remote runtime asset service.

Use the blocks individually or combine them with core WordPress blocks to create complete page sections.

== Installation ==

1. In WordPress, go to Plugins > Add New Plugin.
2. Search for “Genial Blocks”, or choose Upload Plugin to install a ZIP file.
3. Activate Genial Blocks.
4. Open the block inserter and choose a block from the Genial Blocks category.

== Frequently Asked Questions ==

= Does Genial Blocks require another page builder? =

No. Genial Blocks is built for the native WordPress block editor.

= Which blocks are included? =

Genial Blocks includes Advanced Heading, Advanced Button, Info Box, Accordion, Counter, Icon List, Tabs, Pricing Table, Progress Bar, and Container.

= Does the Pricing Table process payments? =

No. Pricing Table presents plan and pricing information with an optional CTA link. It does not process payments.

= Does Genial Blocks require remote runtime assets? =

No. The plugin bundles its curated icon set and does not require an external runtime asset service.

= Does Genial Blocks support responsive layouts? =

Yes. Container provides responsive width, direction, alignment, justification, and gap controls. Advanced Button, Info Box, and Pricing Table also provide focused responsive controls.

= What are the minimum requirements? =

Genial Blocks requires WordPress 6.8 or newer and PHP 7.4 or newer.

== Source Code and Development ==
