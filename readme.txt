Native, accessible WordPress blocks for headings, buttons, content, and layouts.

== Description ==

Advanced Heading supports semantic levels, native alignment, typography, color,
spacing, and an optional subtitle. Advanced Button provides accessible link
behavior, target safety, layout, colors, borders, and spacing controls. Info Box
provides a curated local icon set, semantic content levels, optional CTA links,
colors, borders, and spacing. Accordion provides accessible multi-item
disclosure controls. Counter provides numeric statistics with reduced-motion-
aware enhancement. Icon List provides repeatable curated icons with optional
safe links. Tabs, Pricing Table, Progress Bar, and Container provide additional
native content and layout building blocks.

Source code: https://github.com/GenialSouls/genial-blocks

== Installation ==

1. Install the ready-to-use Genial Blocks ZIP from **Plugins > Add New > Upload
   Plugin**, or search for “Genial Blocks” in the WordPress plugin directory.
2. Activate Genial Blocks from the Plugins screen.
3. Insert any Genial Blocks block from the block inserter.

== Frequently Asked Questions ==

= Does this plugin require another page builder? =

No. Genial Blocks uses the native WordPress block editor.

= Does Advanced Button load remote assets? =

No. The plugin does not load remote runtime assets or external services.
